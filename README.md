# Know Your History Quiz App
This project is a short and simple app built using MIT App Inventor as part of the DGL-104 course.
The purpose of this app is to:
- Make the user interested in the Komoks First Nation's history
- Provide it in a very short and concise experience (people tend to skip a lot if too long)
- Be a fun and simple quiz for the user to solve

## Key Features:
- It has a homescreen which links to an info page and the main quiz
- The info page offers a brief history on the Komoks First Nation
- The app has button functions for user interactions
- It has a storage function to store the player high score
- The app has a quiz to test the what the user learned from the info page.
- Repeated use of the storage function for the highscore
